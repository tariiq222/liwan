# Documents
pages: documents document

## Create a new document
page: /documents/new
1. Open «Documents» and press «New document».
2. Enter the «Title». It is the only required field.
3. Write the «Content» if you want. It is optional.
4. Under «Additional details» you can set the «Expiry date», link a record and add «Tags».
5. Press «Create document». New documents are restricted by default.

## Upload a file to a document
page: /documents
1. Open the document.
2. In the files section press «Upload file» and choose the file (maximum 10 MB).
3. If a file with the same name exists, choose «Change the name» or «Upload as a new version».

## Search and filter documents
page: /documents
1. Open «Documents» and type in «Search documents».
2. Use the lists for «Visibility» and the expiry date.
3. Press «Clear filters» to reset.

## Give a person access to a document
page: /documents
1. Open the document and press «Manage access».
2. Choose the «Visibility»: «Restricted» or «Company».
3. Use «Add a person» and set the role «Reader» or «Editor». Keep at least one editor.
4. Press «Save».
