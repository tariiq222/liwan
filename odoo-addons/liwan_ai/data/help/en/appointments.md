# Appointments
pages: appointments

## See the appointment types
page: /appointments
1. Open «Appointments» from the side rail.
2. Under «Appointment types» the list shows each type with its length in minutes.
3. If the list is empty, no appointment type has been added yet.

## Set the booking rules
page: /settings/apps/appointments
1. Open «Settings», then «Appointment settings».
2. In the «Booking times» card, change the default slot length, the minimum notice, how far ahead people can book and the modification deadline.
3. Click «Save changes». Click «Revert» to undo before saving.
4. If you see «View only» you do not have permission to change them.
