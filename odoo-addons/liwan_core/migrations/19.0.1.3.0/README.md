اللون الأساسي الافتراضي للعلامة في `data/res_company_data.xml` (و`DEFAULT_PRIMARY_COLOR` في `liwan_api`) يتغير من
`#18181b` إلى منتصف الليل `#13234a`. السجل `base.main_company` معلَّم `noupdate="1"` فلا تعيد الترقية كتابة قيمة قاعدة
قائمة، ولا يوجد عملاء حاليون، فلا ترحيل بيانات. التثبيت الجديد فقط يأخذ القيمة الجديدة.
