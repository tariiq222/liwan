# Cyan Meeting Minutes

Vendor module (Cyan, LGPL-3) with Nasq hardening. See `PROVENANCE.md`.

Internal meeting minutes, resolutions, calendar link, and activities.

Access is company-scoped. Meeting Manager is an explicit group (not Settings).
Participants (organizer, secretary, attendees) can read. Only organizer,
secretary, and managers edit draft/confirmed minutes. Approved or cancelled
meetings are immutable until a manager reopens them. Assignees still update
resolution progress and completion notes after approval.
