# 19.0.1.3.0

الإصدار يضيف موديل `liwan.tenant.branch` الجديد (جدول فارغ) وثلاثة حقول تجارية اختيارية
(`commercial_revision_id`, `commercial_digest`, `commercial_applied_at`) على `liwan.tenant.profile`، وميزة الحد
`branches.extra_limit`. الأعمدة الجديدة قابلة للقيمة الفارغة، وORM ينشئها عند التحديث. الترحيل `post-branch_limit.py` يضيف مفتاح `branches.extra_limit` (القيمة `null` = بلا حد) إلى سياسة ميزات قائمة لتوفير تمثيل صريح للحد القديم غير المحدود. هذا ترحيل بيانات للسياسات القائمة؛ يبقى الكتالوج القديم والطلب الموقّع دون تعديل. يقبل التحقق من القراءة هذه الإضافة وحدها عندما أغفل الطلب القديم المفتاح، وتبقى القيمة الصريحة `0` مختلفة ومُلزِمة.
