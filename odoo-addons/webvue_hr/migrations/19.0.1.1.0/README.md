# 19.0.1.1.0

ينقل هذا الإصدار قدرات الموارد البشرية الثماني ومجموعاتها ودور `hr_manager` وسطري الوصول المرتبطين بالأرشفة من
`webvue_core` إلى `webvue_hr`. لا يحتاج `webvue_hr` ترحيلاً خاصاً: ترحيل
`webvue_core/migrations/19.0.1.1.0/pre-move_app_xmlids.py` يعيد تسمية صفوف `ir_model_data` قبل تحميل البيانات،
فتتبنّاها ملفات `webvue_hr` بالمعرّفات نفسها دون إنشاء سجلات جديدة، وتبقى إسنادات الأدوار وعضويات المجموعات كما هي.
