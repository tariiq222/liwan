## السلوك المسلم

- سياسة المستأجر حقول JSON مع قفل صف عند الحصص.
- سحب ميزة: قراءة تاريخية، كتابة `403 feature_not_included`.
- معلّق: لا دخول عميل ولا جلسة قائمة؛ الدعم يدخل حتى يُعطَّل.
- منتهٍ: دخول وقراءة وتغيير كلمة المرور؛ لا كتابة أعمال.
- الحدود تُحسب على المؤسسة كلها وتُرفض الزيادة داخل المعاملة.
- `/me` يرسل `modules` و`entitlements` و`platform` و`terminology`.
- الواجهة تخفي الوحدة المسحوبة إذا وُجدت قائمة الميزات؛ الهوية بلا سياسة تبقى على القدرات فقط.
