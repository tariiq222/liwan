## الإصلاحات

- ترتيب مرفقات المهام المباشرة حسب ID في المساعد المملوك لـPMO، بعد تطبيق مرشحات الربط والنوع واستبعاد مرفقات المحادثة. لا تغيير لقواعد الوصول أو نطاق الشركة. اختبار API جديد يغطي رفع أزواج ملفات مع ملفات لمهام أخرى؛ فشل قبل الإصلاح ثم نجح بعده.
- نقل اختبارات الاجتماعات التي تنشئ شركات ومستخدمين إلى `post_install`؛ مرحلة التحديث الجزئية لا تحمل امتداد المالية الافتراضي لحقل `res.partner.autopost_bills` رغم وجود عموده الإلزامي في قاعدة الإصدار. بقيت اختبارات تركيب الصلاحيات الأربعة عند `at_install`، وفُصل اختبار المستخدمين في صنف لاحق. لا تخطٍ لاختبارات ولا تعديل لاختيار المشغل أو اعتماد جديد على المالية.
- تثبيت `invoice_date_due` في بيانات فاتورة الاختبار ذات التاريخ الثابت؛ Odoo يختار تاريخ اليوم عند تركه فارغًا. بقيت تأكيدات تقرير المالية كما هي.
- إصلاح اختبار عقد الاجتماعات ليؤكد وجود اللقطة قبل الوصول الاختياري إلى خصائصها. بقي العقد الإنتاجي يقبل `snapshot: null`، ولا استخدام لإلغاء فحص الأنواع.

التغييرات البرمجية محصورة في ثمانية ملفات: مساعد المرفقات واختبار العد في PMO، بيانات اختبار المالية المشتركة، أربعة ملفات اختبارات الاجتماعات، واختبار `workspace.test.ts` في عقود الاجتماعات. أُثبت بالبصمات أن بقية ملفات إحلال DMS السابقة لم تتغير.
