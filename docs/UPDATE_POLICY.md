# سياسة تحديث مصادر GitHub — 2026-09-10

ألغى طارق هوك الموافقة على تحديثات المصادر؛ الإلغاء يخص الهوك وسجله، ولا يلغي الموافقة البشرية المذكورة أدناه ولا بوابات GitHub للتسليم.
قبل تغيير نسخة مصدر خارجي معتمدة من GitHub، اعرض التغييرات وأثرها وانتظر موافقة طارق في المحادثة. لا يعني فحص metadata أو قراءة مصدر أو جلب مراجع Git وحده اعتماد نسخة جديدة أو دمجها.
التثبيت والبناء والمعاينة والاختبارات المحلية للنسخ المعتمدة لا تتطلب موافقة تحديث؛ تبقى حدود العزل والتفويض للعمل نفسه سارية. لا تُعد هذه العبارة تفويضًا لتغيير dependency أو lockfile أو مصدر Odoo.
