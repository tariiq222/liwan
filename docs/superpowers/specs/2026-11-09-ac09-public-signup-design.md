# AC-09 public signup

The [hosting contract](liwan-shared-saas-and-sovereign-deployment.md) owns acceptance. On November 9 the owner approved Authentica for SMS and proof of email ownership before provisioning. Use the existing SMTP adapter for the email code and the existing tenant invitation for initial password setup.

The SaaS prospect host serves the public register page. Its same-origin POST routes send strictly parsed requests to the control plane over the existing anonymous service-signature channel. Bind the signature to the edge-derived IP and the raw body. The route grants no Odoo, vendor or billing privileges and exposes no workspace identifiers. The browser holds the opaque challenge ID only for the current flow.

Collect administrator and company names, email and Saudi mobile. Normalize Saudi mobile to +966 and trim and case-fold email. A signup lasts 30 minutes. Codes expire after 5 minutes and permit 5 attempts per issuance. Email issuance requires a verified mobile. Reserve delivery budget in PostgreSQL before calling a sender. Per channel the starting limits are one delivery per destination per minute, three per destination per hour, ten per source per hour (IPv6 grouped by /64) and a configurable global daily cap. Source and destination budget keys use HMAC. Codes are bound to signup ID and channel and stored as keyed digests. No plaintext codes or contact data are recorded in logs.

Successful email verification, claiming the verified identities, inserting the customer and creating its zero-due trial order occur in a single transaction. Each normalized email and mobile can claim one public trial. The claim is independent of edits to the resulting tenant's administrator and the rule applies to self-service trials. Retries with the original code within its validity return the same generic acknowledgement. The commercial worker owns tenant provisioning and invitation delivery. Existing operator recovery applies after the transaction commits. Expired incomplete signups and delivery-budget entries are pruned during issuance.

The operator chooses one published, available, public plan revision with a monthly price and a 14-day trial, using server configuration. The visitor starts with its included quantities, zero optional bundles and zero extra branches. The trial needs no payment method. The prospect signup stays disabled by default. Live SMS depends on a Liwan Authentica key and approved template. Bank and Moyasar conversion stay in the existing customer billing paths. The live provider, tenant delivery and conversion evidence must be reported separately from a simulated signup.
