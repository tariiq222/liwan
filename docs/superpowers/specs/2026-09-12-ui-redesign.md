**6. ترتيب التنفيذ والملكية**

1. **تثبيت نقطة البداية وعقد التصميم:** تسجيل main والتعديلات الحالية وبصمة المرجع، وإنشاء بيئة مؤقتة مستقلة. إنشاء جرد لكل صفحة ووظيفة وإجراء وحقل وفلتر وخيار عرض، مع صلاحياته ومساره وسلوكه الحالي ومكانه المقترح واختبار مطابقته. تسوية فرق Vue/HTML وتحديث DESIGN.md لتحديد الشكل الجديد وقيد عدم تغيير الوظائف.
2. **الأساس المشترك:** تنفيذ التوكنات ووصفات Nuxt UI والغلاف والتنقل والجوال، وإعادة تصميم PageHeader/FilterBar/FormSection/PageState/DateField/FileField. هذه حزمة بمالك واحد لأنها تشترك في كل الصفحات. تنفذ لها عينة من قائمة مشروع وتفصيل مهمة ونموذج ومالية ذات حالة فراغ؛ تقارن بصريًا قبل التعميم.
3. **تطبيق الشكل على طرق العرض الموجودة:** إعادة تنسيق الصفحات واللوحات الحالية مع إبقاء منطق الراوتر وProjectRouteHost وProjectRouteModal وحماية المسودة والعودة والفلاتر والروابط المباشرة وخيار الصفحة الكاملة. التغييرات في هذا النطاق تخص القالب والمظهر فقط؛ لا إعادة تصميم لسير العمل.
4. **ترحيل الوحدات بالتوازي بعد استقرار الأساس:** حتى ثلاث حزم Luna high مستقلة: (أ) المشاريع والمهام والقوالب؛ (ب) الاجتماعات والمحادثات والإشعارات؛ (ج) المؤسسة والإعدادات والحساب والدخول. تقسّم داخليًا إلى دفعات متماسكة عند الحاجة؛ توزع اختبارات كل وحدة مع مالكها. كل brief يتضمن جرد وظائف الحزمة وقيد إبقاء handlers/composables والعقود والصلاحيات والحسابات دون تغيير. Astra يملك المكونات المشتركة والتكامل والتحقق، ولا يكتب عاملان نفس الملف. لا تعديل backend أو contracts ضمن المهمة.
5. **التنظيف والفحوص في الدفعة نفسها:** نقل محولات الرسم، حذف CSS والمكونات والمراجع المتقاعدة، تحديث أدوات المنع والاختبارات والتوثيق، ثم فحص المنتج الموحد. لا يُسلّم للمستخدم انتقال جزئي بوصفه مكتملًا.

بيئات التنفيذ لها node_modules و.nuxt ومنافذ وقواعد بيانات اختبار مستقلة. لا اختبارات على `odoo19`. الدمج والنشر لهما صلاحياتهما عند الوصول إليهما.

**8. كيف نثبت الاكتمال**

- جرد شامل يغطي 91 ملف صفحة وكل مكوّن إنتاجي، مع حالة ترحيل ومراجعة معروفة لكل مسار؛ يشمل التفاصيل والإنشاء والتعديل والإعدادات والطباعة والصفحات الفارغة أو المقيدة بالصلاحيات.
- مطابقة كل وظيفة قبل وبعد: نفس المدخلات والحقول والإجراءات والفلاتر وخيارات العرض والصلاحيات والنتائج وخطوات الحفظ والإلغاء. يمكن أن يتغير موضع العنصر فقط. كل عنصر بالجرد له مكان فعلي قابل للوصول في التصميم الجديد؛ أي حذف أو إخفاء أو تعطيل أو اختلاف وظيفي يمنع قبول الدفعة.
- صفر استيرادات أو auto-imports أو selectors أو تعليمات نشطة تشير إلى التصميم المتقاعد، وصفر بيانات mock أو أزرار وهمية في تشغيل العميل. الأسماء القديمة داخل أدوات المنع نفسها توثّق سببها ولا تعد مستهلكًا.
- `tools/ui_policy.py` يُحدّث لإزالة grandfathering والملاك المتقاعدين، و`ui_inventory.py` يمنع وجود شجرة UI القديمة بعد انتقال الرسوم. الفحص الحالي يستثني components/ui ويكتفي بجوانب من الاستخدام؛ نجاحه وحده لا يثبت النظافة.
