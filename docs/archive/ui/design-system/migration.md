# UI migration

حالة الواجهة: Nuxt UI هو سطح التحكم في `apps/web`. السياسة الوحيدة هي
[DESIGN.md](../../../../DESIGN.md)، والفهرس في [components.md](../../../design-system/components.md) يسجل
مالكي المكونات المركبة الفعلية.

لا يوجد مسار ترحيل ثانٍ أو مصدر HTML داخل المستودع. لا تُنقل بيانات المرجع
الخارجي أو composables النموذجية إلى التشغيل. الاحتفاظ بمسارات URL والعقود
والصلاحيات والحقول والفلاتر والحسابات وسلوك المسودات شرط لكل تغيير بصري.

التنظيف المرحلي لا يحذف مكونًا أو CSS إلا بعد نقل semantics المطلوبة إلى
المالك الجديد وإثبات انعدام المستهلكين. الرسوم تبقى عبر Unovis؛ يملك Task 6
محولات الرسوم التخصصية في `apps/web/app/components/charts/**` مع بقاء
`DashboardChart.client.vue` وواجهته وسلوكه.
