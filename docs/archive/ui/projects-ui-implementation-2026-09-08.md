## التغييرات المنفذة

- إنشاء المشروع يبدأ بالاسم والوصف والمدير والتواريخ، ثم ثلاثة أقسام اختيارية قابلة للفتح. لا يظهر الرمز الذي يولّده النظام كحقل إنشاء. الأخطاء تفتح القسم المعني.
- ملف المشروع في وضع القراءة يعرض قيمًا وعناوين واضحة بدل نموذج معطل. إلغاء التعديل يحمي المسودة، بما في ذلك تغيير `?edit=1` داخل المسار نفسه.
- قائمة المشاريع تعرض عدد النتائج الحقيقي، مع إبقاء الإحصاءات في لوحة المشاريع؛ أزيلت المؤشرات التي كانت تحسب أول صفحة فقط.
- التنقل السياقي يحفظ فلاتر قائمة المشاريع والمهام عبر الإعدادات والمالية وملف المشروع. سجل التحديثات له صفحة مستقلة تصرّح بحد آخر 50 تحديثًا.
- تنظيم تفاصيل ونماذج الأطراف والمخاطر والمشكلات والمالية والقوالب إلى أقسام واضحة، مع إجراءات الصفحة في موضعها وتخفيف الصناديق المتداخلة.
- توضيح أدوار مصفوفة المسؤوليات، وفصل تمرير الجداول الواسعة عن الصفحة. إبقاء تقدير ميزانية ملف المشروع منفصلًا عن ملخص بنود المالية الفعلية.
- تحسين عرض سجل المهمة للقيم الفارغة والتواريخ والحقول، وتعريب أدوات الرسوم باستخدام ترجمة ECharts الموجودة.
- إصلاح خطأ SSR في المراحل والمعالم المرتبطة بمهام بسبب غياب TooltipProvider، مع اختبار فعلي لكل حالة. استكمال سبعة مفاتيح ترجمة اكتشفتها مراجعة المتصفح.
