# مراجع واجهة نسق

المرجع الملزم للواجهة هو [DESIGN.md](../../DESIGN.md).

- [فهرس المكونات](components.md): ملكية مكونات التشغيل ومساراتها؛ اللبنات العرضية في `packages/ui` (طبقة Nuxt مشتركة) والمرتبطة بتطبيق في `apps/web/app`.
- [كتالوج المكونات الآلي](catalog.json): خصائص مكونات Storybook وأحداثها وفتحاتها وقصصها، يولّده `node tools/ui_catalog.mjs` ولا يُحرَّر يدويًا؛ يفحصه `npm test`.
- [مرجع Nuxt UI](nuxt-ui-reference.md): حدود المكتبة ومصادر الثيم والحالة.
- [الأرشيف](../archive/ui/README.md): مواد تاريخية لا تنشئ سياسة واجهة.
